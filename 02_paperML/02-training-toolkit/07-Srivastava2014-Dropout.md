# Dropout：用"随机删神经元"训练指数级的模型集成
**Dropout: A Simple Way to Prevent Neural Networks from Overfitting**
Srivastava, Hinton, Krizhevsky, Sutskever & Salakhutdinov · *JMLR* 15:1929–1958 · 2014

---

## 一句话总结

大网络强大但极易过拟合。最可靠的抗过拟合手段是"训练很多个不同模型再平均"，可惜对大网络太贵——训不起、也跑不起。Dropout 用一个近乎魔术的把戏绕过了这个矛盾：**训练时，每个神经元以概率 $1-p$ 被临时清零**。这等价于每次都在训练一个不同的"瘦网络"，而所有瘦网络共享权重。一个 $n$ 单元的网络因此暗含 $2^n$ 个子网络。测试时只用一个网络、把权重乘以 $p$——这恰好近似了对那 $2^n$ 个模型做集成平均。**一行 Bernoulli 掩码，换来一个指数级的模型集成。**

> "By dropping a unit out, we mean temporarily removing it from the network, along with all its incoming and outgoing connections. … This prevents units from co-adapting too much."

## 1. 历史定位：AlexNet 背后的关键零件，单独成篇

Dropout 的故事和 AlexNet（#6）交织在一起：

- **2012 年 7 月**：Hinton 团队挂出 arXiv 论文《Improving neural networks by preventing co-adaptation of feature detectors》——dropout 的最初版本。
- **2012 年 9 月**：AlexNet 夺得 ImageNet 冠军，其全连接层正是靠 dropout 压住 6000 万参数的过拟合。
- **2014 年**：这篇 JMLR 长文（30 页）是 dropout 的**正式、完整版**——补全了数学解释、跨领域实验（视觉/语音/文本/基因）、与贝叶斯网络和其他正则化的系统对比。

所以本篇和 AlexNet 是同一波工作的两个侧面：AlexNet 证明"深度 + 规模"可行，Dropout 解决"规模带来的过拟合"。两者缺一,2012 的胜利都不完整。

Dropout 也是深度学习史上少见的"想法极简、影响极大"的论文——核心思想一句话讲完，却成为之后近十年每个网络的标配，直到 BatchNorm（#8）和大数据让它在卷积网络里逐渐退居二线（但在 Transformer 里至今仍在用）。

## 2. 待解问题：模型集成太贵

### 2.1 为什么要集成

机器学习有个铁律：**把多个不同模型的预测平均起来，几乎总能降低测试误差**（随机森林、Netflix 大奖的获胜方案都是集成）。集成有效的前提是各个模型要"够不一样"——要么结构不同，要么训练数据不同。

理论上的黄金标准更进一步：对参数的**所有可能取值**做预测平均、按后验概率加权——这就是贝叶斯方法。但它需要无限算力。

### 2.2 为什么对大网络行不通

对深度网络，集成有三重劝退：
1. **训练贵**：训练一个大网络就要好几天，训练几十个？训不起。
2. **调参贵**：每个不同结构都要单独搜超参。
3. **数据不够**：要让模型不同，得用不同数据子集训练，但数据本来就不够分。
4. **推理贵**：就算训出来了，测试时跑几十个大网络，延迟无法接受。

**矛盾**：集成几乎稳赚，但对大网络的成本无法承受。Dropout 就是来破这个局的。

## 3. 核心思想：一个网络 = 指数级子网络的集成

### 3.1 训练时——随机抽一个"瘦网络"

每次给网络喂一个训练样本时，让每个神经元**以概率 $1-p$ 被临时删除**（连同它的所有进出连接）。被删的神经元这一步不参与前向、不参与反向。

于是每个样本看到的，都是从完整网络里**随机抠出来的一个"瘦网络 (thinned network)"**。一个 $n$ 单元的网络，瘦网络的可能形态有 $2^n$ 种（每个单元在/不在）。

关键在于：**这 $2^n$ 个瘦网络全部共享同一份权重**。所以训练一个 dropout 网络，等价于**同时训练 $2^n$ 个高度权重共享的瘦网络**——每个瘦网络只被它碰巧出现的那些样本训练到，几乎"各自只训练了一两次"。

论文建议：隐藏单元 $p=0.5$（最优且对大量任务通用），输入单元 $p$ 接近 1（约 0.8——输入信息太宝贵，不舍得删太多）。

### 3.2 测试时——权重缩放近似集成

测试时不能真的去跑 $2^n$ 个网络求平均。论文的妙招：**用一个完整网络，但把每个权重乘以 $p$**。

$$W^{(l)}_{\text{test}} = p\,W^{(l)}$$

**为什么乘 $p$？** 看一个神经元的输入。训练时它收到的净输入是

$$z = \sum_j r_j\,w_j\,y_j, \qquad r_j \sim \text{Bernoulli}(p)$$

$r_j$ 是 Bernoulli 掩码，期望 $\mathbb{E}[r_j]=p$。所以这个净输入的**期望**是

$$\mathbb{E}[z] = \sum_j \mathbb{E}[r_j]\,w_j\,y_j = \sum_j p\,w_j\,y_j = \Big(\sum_j (p\,w_j)\,y_j\Big)$$

也就是说，**测试时用 $pW$ 算出的净输入，恰好等于训练时净输入的期望值**。这保证了每个隐藏单元在测试时的输出，与它训练时（在 dropout 噪声分布下）的期望输出一致。

论文进一步指出：这个权重缩放，是对 $2^n$ 个瘦网络预测分布做**几何平均**的一个很好的近似。一行缩放，把指数级集成压缩进单次前向。

### 3.3 前向方程对比（论文 Section 4）

标准网络（第 $l$ 层到 $l+1$ 层）：

$$z^{(l+1)}_i = \mathbf{w}^{(l+1)}_i\,\mathbf{y}^{(l)} + b^{(l+1)}_i, \qquad y^{(l+1)}_i = f(z^{(l+1)}_i)$$

加 dropout 后，多出一个掩码步骤：

$$r^{(l)}_j \sim \text{Bernoulli}(p), \qquad \widetilde{\mathbf{y}}^{(l)} = \mathbf{r}^{(l)} * \mathbf{y}^{(l)}, \qquad z^{(l+1)}_i = \mathbf{w}^{(l+1)}_i\,\widetilde{\mathbf{y}}^{(l)} + b^{(l+1)}_i$$

$*$ 是逐元素乘。整个 dropout 就是在激活向量上**点乘一个随机 0/1 掩码**——实现简单到只有一行。

## 4. 为什么有效：两个绝妙的类比

论文 Section 2 没有用数学解释 dropout 为什么有效，而是给了两个生物/社会学类比，意外地深刻。

### 4.1 有性繁殖的类比

无性繁殖直接复制亲本一整套基因——能把"一组配合得很好的基因"原样传下去。有性繁殖却把双亲基因各取一半重组——会**打散这些精心配合的基因组合**。直觉上无性繁殖应该更优，可为什么高等生物几乎都选择了有性繁殖？

论文引用 Livnat 2010 的理论：长期看，自然选择优化的不是"个体适应度"，而是基因的**"混合能力 (mix-ability)"**——一个基因能否和**随机的**其他基因组合还照样好用。一个基因不能指望某个固定搭档永远在场，必须学会**独立地或与少量伙伴一起**做有用的事。

类比到网络：dropout 训练下，每个隐藏单元必须能和**随机抽到的其他单元**协作。它不能依赖某个特定伙伴来帮它纠错——于是被迫**独立地学到有用的特征**。这就是 dropout 防止"共适应 (co-adaptation)"的本质。

### 4.2 阴谋的类比

要搞一场大破坏：是搞 10 个各 5 人的小阴谋好，还是 1 个 50 人的大阴谋好？大阴谋若 50 人配合无误威力更大，但只要环境一变、有一环出错就全盘崩溃。**10 个小阴谋更鲁棒**——各自独立，坏一个不影响其余。

类比：复杂的"共适应"（一大群神经元精密配合）能在训练集上拟合得很好，但在新数据上极易整体失效；多个简单、独立的特征则鲁棒得多。Dropout 强迫网络走后一条路。

## 5. 代码骨架与训练要点

### 5.1 代码骨架

```python
import torch

def dropout_train(y, p=0.5):
    """训练时：Bernoulli 掩码。论文原版——测试时需把权重乘 p。"""
    mask = (torch.rand_like(y) < p).float()
    return y * mask

def dropout_inverted(y, p=0.5):
    """现代'倒置 dropout'：训练时除以 p，测试时代码完全不变。"""
    mask = (torch.rand_like(y) < p).float()
    return y * mask / p

# PyTorch 内置：nn.Dropout(p) 的 p 是'丢弃概率'，与论文的'保留概率 p'相反！
import torch.nn as nn
net = nn.Sequential(
    nn.Linear(784, 1024), nn.ReLU(), nn.Dropout(0.5),   # 丢弃 50%
    nn.Linear(1024, 1024), nn.ReLU(), nn.Dropout(0.5),
    nn.Linear(1024, 10),
)
net.train()   # dropout 生效
net.eval()    # dropout 关闭，自动按倒置方式处理缩放
```

⚠️ 注意一个易错点：论文里的 $p$ 是**保留概率**，而 PyTorch `nn.Dropout(p)` 的 $p$ 是**丢弃概率**——两者相反。论文的 "$p=0.5$ 保留" 对应 `nn.Dropout(0.5)`，恰好相等只是巧合。

### 5.2 训练要点：dropout 的好搭档

- **Max-norm 正则化**：约束每个隐藏单元的入权重向量范数 $\|\mathbf{w}\|_2 \le c$。论文发现 dropout + max-norm 效果显著优于单用 dropout。原理：max-norm 把权重锁在半径 $c$ 的球内，使你能用**很大的学习率**而不怕权重爆炸；dropout 的噪声则让优化去探索更多权重空间。
- **大学习率 + 高动量**：dropout 引入的噪声需要更激进的优化来对抗。
- **收敛变慢**：因为每步只训练一个瘦网络，dropout 网络收敛所需迭代数大约**翻倍**。这是它的主要代价。

## 6. 实验结果与意义

论文在 7 个跨领域数据集上测试——视觉（MNIST/SVHN/CIFAR/ImageNet）、语音（TIMIT）、文本（Reuters）、基因（剪接预测）。结论简单粗暴：**dropout 在所有数据集上都提升了泛化**。

MNIST（置换不变设定）的消融最能说明问题：

| 配置 | 错误率 |
|---|---|
| 标准网络（无 dropout） | 1.60% |
| + Dropout | 1.35% |
| + Dropout + ReLU | 1.25% |
| + Dropout + ReLU + max-norm | 1.06% |
| + 更大网络（2 层 ×8192） | 0.95% |

一个值得注意的细节：那个 8192×8192 的网络有 **6500 万参数**、却只在 6 万样本上训练——常规正则化 + 早停几乎必然过拟合，**dropout 让它连早停都不需要**。

跨领域亮点：SVHN 卷积网络 3.95% → 2.55%（在卷积层也用 dropout）；CIFAR-100 从 43.48% → 37.20%。一个有意思的发现：**给卷积层也加 dropout 仍有效**——虽然卷积层参数少、本身不太过拟合，但它给上层全连接层提供了"带噪输入"，间接防止上层过拟合。

意义分层：

1. **直接结论**：一个极简、计算几乎免费的技巧，普适地抗过拟合。
2. **集成视角**：把"训练单个网络"重新诠释为"训练 $2^n$ 个共享权重的网络的集成"——这个视角后来启发了大量工作。
3. **与贝叶斯方法的关系**：论文明说 dropout 是"等权重的几何平均集成"，而贝叶斯网络是"按后验加权的集成"——贝叶斯更正确但慢，dropout 是它的廉价近似。这条线后来长成 **MC Dropout**（Gal & Ghahramani 2016：测试时也开 dropout、多次采样，用来估计不确定性）。
4. **工程标配**：2014–2018 年，几乎每个网络都用 dropout。

## 7. 常见误解与澄清

| 误解 | 实情 |
|---|---|
| "Dropout 在所有网络里都该用" | 现代卷积网络里 dropout 已大幅退场——BatchNorm（#8）自带正则效果，两者叠加常常互相干扰。但在 **Transformer**（#24）里 dropout 至今仍是标配。用不用要看架构。 |
| "测试时也要随机删神经元" | 标准 dropout 测试时**不删**，用完整网络 + 权重缩放。"测试时也开 dropout"是另一回事——MC Dropout，专门用来估计预测不确定性。 |
| "p 是丢弃概率" | 论文里 $p$ 是**保留**概率（$p=0.5$ 表示保留一半）。但 PyTorch/Keras 的 `Dropout(p)` 里 $p$ 是**丢弃**概率。读代码和读论文时务必分清。 |
| "现代实现测试时要乘 p" | 现代用的是**倒置 dropout (inverted dropout)**——训练时就除以 $p$，测试时代码完全不动。效果等价，但部署更省心。 |
| "Dropout 就是加噪声，没什么特别" | 它确实是一种噪声正则化，但"$2^n$ 子网络集成 + 权重共享 + 权重缩放近似几何平均"这一整套解释，是它区别于普通加噪的精髓。 |
| "Dropout 让网络更准" | 准确说：dropout 降低**测试**误差（泛化），通常会**升高训练**误差、并让收敛变慢一倍。它是拿训练代价换泛化。 |

## 8. 局限与后续填坑

| Dropout 的局限 | 后续解药 / 演化 | 关键论文 |
|---|---|---|
| 收敛速度慢一倍 | BatchNorm 自带正则，可减少对 dropout 的依赖 | BatchNorm (#8) |
| 与 BatchNorm 叠加会互相干扰 | 二选一，或调整放置顺序 | Li et al. 2018《Disharmony…》 |
| 标准 dropout 对卷积层效果有限 | 空间结构化的 DropBlock / SpatialDropout | Ghiasi et al. 2018 |
| 无法给出预测不确定性 | MC Dropout：测试时多次采样 | Gal & Ghahramani 2016 |
| 随机性是"事后近似" | 解析地积分掉噪声 → 确定性正则 | 本文 Section 9 (marginalized dropout) |
| 对 RNN 时间步直接用会破坏记忆 | 变分 dropout（同序列各步同掩码） | Gal & Ghahramani 2016 |
| Transformer 时代它仍重要但需精细放置 | attention dropout / residual dropout 的位置讲究 | Transformer (#24) 及后续 |

## 9. 与本路线图后续论文的关联

- **#6 AlexNet**：dropout 是 AlexNet 全连接层抗过拟合的关键零件，本篇是它的完整理论版。
