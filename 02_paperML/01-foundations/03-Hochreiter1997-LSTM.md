# LSTM：给循环网络造一条"恒定误差传送带"
**Long Short-Term Memory**
Hochreiter & Schmidhuber · *Neural Computation* 9(8), 1735–1780 · 1997

---

## 一句话总结

循环网络理论上能记住任意久远的信息，实践中却记不住超过 ~10 步——因为反向传播的误差信号会**指数级衰减或爆炸**。这篇论文先用一页纸的数学**精确证明了这个衰减率**，然后给出解药：在网络里嵌入一个自连接权重恒为 1.0 的线性单元（"恒定误差传送带" CEC），再用**乘法门**控制信息何时进、何时出。结果是 LSTM 能跨越 **1000 步以上**的时间间隔学习。从 1997 到 2017 Transformer 出现前，几乎所有序列建模——语音识别、机器翻译、手写识别——都站在这个架构上。

> "LSTM can learn to bridge minimal time lags in excess of 1000 discrete time steps by enforcing *constant* error flow through 'constant error carousels' within special units."

---

## 1. 历史定位：一个被忽视了 6 年的诊断

故事要从 1991 年说起。Sepp Hochreiter 的硕士论文（德语，《Untersuchungen zu dynamischen neuronalen Netzen》）第一次**严格分析了"为什么循环网络学不会长程依赖"**。但这篇论文是德语的、是硕士论文，几乎没人读。

与此同时，Bengio et al. 1994 用英语独立得到了类似结论（"Learning long-term dependencies with gradient descent is difficult"），这才让"梯度消失"问题进入主流视野。

1997 年的这篇 LSTM 论文做了两件事：(1) 把 Hochreiter 1991 的诊断用英语重新讲清楚；(2) 给出一个**真正能用的解药**。它发表在《Neural Computation》上，全文 46 页——是本路线图里最长、最技术密集的论文之一。

值得注意的时间线：**LSTM 提出于 1997，但直到 2007–2015 才真正流行**。这中间隔了十年，因为它需要等到算力、数据、以及 Graves 等人把它用于语音和手写识别的工程突破。LSTM 和 LeNet 一样，是"对了，但早了十年"的典型。

## 2. 待解问题：梯度消失的精确数学

### 2.1 朴素图景

循环网络处理序列时，第 t 步的隐藏状态依赖第 t−1 步，t−1 依赖 t−2……要学会"第 1000 步的输出依赖第 1 步的输入"，误差信号必须从第 1000 步一路反向传播回第 1 步。

直觉上你可能觉得"传就传呗"。论文证明：**传不回去**。

### 2.2 论文 Section 3.1 的核心推导

设输出单元 k 在 t 时刻的误差信号（标准 BPTT）：

$$\vartheta_k(t) = f_k'(net_k(t))\,(d_k(t) - y^k(t))$$

非输出单元 j 的反传误差：

$$\vartheta_j(t) = f_j'(net_j(t)) \sum_i w_{ij}\,\vartheta_i(t+1)$$

现在问：误差从单元 u（t 时刻）反传 q 步到单元 v，会被缩放多少倍？论文的公式 (1)（递归形式）经归纳法得到公式 (2)：

$$\frac{\partial \vartheta_v(t-q)}{\partial \vartheta_u(t)} = \sum_{l_1=1}^{n}\cdots\sum_{l_{q-1}=1}^{n}\;\prod_{m=1}^{q} f_{l_m}'(net_{l_m}(t-m))\,w_{l_m l_{m-1}} \tag{2}$$

别被符号吓到，关键只看那个**连乘 $\prod_{m=1}^{q}$**：误差反传 q 步，就要把 q 个 $f'\cdot w$ 因子**连乘**起来。

### 2.3 致命的连乘

连乘的结果只有三种命运：

- 如果每个 $|f_{l_m}'\cdot w| > 1$ → 连乘**指数爆炸** → 梯度爆炸，权重震荡，训练发散。
- 如果每个 $|f_{l_m}'\cdot w| < 1$ → 连乘**指数衰减** → 梯度消失，远处的误差信号到达时已经趋近于 0，网络学不到长程依赖。
- 恰好 = 1 → 才能保持。但这是测度为零的刀锋，随机初始化几乎不可能落上去。

论文把它量化得更狠。如果激活函数是 logistic sigmoid，$f'$ 的最大值才 **0.25**。所以只要权重 $|w| < 4.0$，就有 $|f'\cdot w| < 1$，误差必然指数衰减。论文给出的弱上界：

$$\left|\frac{\partial \vartheta_v(t-q)}{\partial \vartheta_u(t)}\right| \le n\,(\tau)^q, \qquad \tau = \frac{n\,w_{max}}{4.0} < 1.0$$

**结论**：用 sigmoid 的常规循环网络，长程梯度注定消失。而且论文特别指出——**加大初始权重没用**（权重大了 $f'$ 反而衰减更快），**加大学习率也没用**（它不改变长程/短程误差流的比例）。这是一个结构性的死局，不是调参能解决的。

## 3. 核心思想：恒定误差传送带 CEC

### 3.1 从死局倒推解药

既然问题出在"误差反传每步都被 $f'\cdot w$ 缩放"，那解药就直白了：**让这个缩放因子恰好等于 1**。

考虑一个**自连接**的单元 j（它连到自己，权重 w_jj）。要让误差穿过这个自连接时不缩放，需要：

$$f_j'(net_j(t))\,w_{jj} = 1.0$$

把这个微分方程积分（论文 Section 3.2）得到：$f_j$ 必须是**线性函数**，而且单元的激活必须保持恒定。最简单的解：

$$f_j(x) = x \quad(\text{恒等函数}), \qquad w_{jj} = 1.0$$

于是这个单元变成：

$$y_j(t+1) = f_j(net_j(t+1)) = f_j(w_{jj}\,y_j(t)) = y_j(t)$$

它**原封不动地把自己的状态传到下一个时刻**。误差反传穿过它时，缩放因子恒为 1——既不消失也不爆炸。论文给它起名 **Constant Error Carousel（恒定误差传送带，CEC）**。这就是 LSTM 的心脏。

### 3.2 朴素 CEC 不够：两个权重冲突

但只有一个自连接 1.0 的线性单元还不够用——它还得连接其他单元来读写信息。一旦加上输入/输出连接，论文 Section 3.2 指出立刻冒出两个冲突：

- **输入权重冲突 (input weight conflict)**：同一个输入权重 w_ji，既要负责"在合适的时刻把输入存进来"，又要负责"在其他时刻挡住无关输入"。这两个目标会产生**互相矛盾的梯度信号**。
- **输出权重冲突 (output weight conflict)**：同一个输出权重 w_kj，既要负责"在合适的时刻把存的信息读出去"，又要负责"在其他时刻保护下游单元不被干扰"。同样矛盾。

直觉：CEC 是一条完美的传送带，但**它没有阀门**。信息一直在传，无法选择性地"现在存""现在读""现在别动"。

## 4. LSTM 架构：CEC + 三种乘法门

### 4.1 给传送带装阀门

论文的解决方案：在 CEC 周围加**乘法门单元 (multiplicative gate units)**。

- **输入门 in_j**：一个 sigmoid 单元，输出 ∈ [0,1]。它的输出乘在"候选输入"上——输出接近 0 就挡住输入，接近 1 就放行。解决输入权重冲突。
- **输出门 out_j**：另一个 sigmoid 单元，输出 ∈ [0,1]。它的输出乘在"细胞输出"上——接近 0 就不让别人读到，接近 1 就放行。解决输出权重冲突。

CEC + 输入门 + 输出门 = 一个**记忆细胞 (memory cell)**，论文 Figure 1 画的就是它。

> ⚠️ **重要**：1997 年的原始 LSTM **没有遗忘门 (forget gate)**！遗忘门是 Gers, Schmidhuber & Cummins 在 1999/2000 年补上的。今天大家说的"标准 LSTM"其实是 LSTM+遗忘门。这一点几乎所有教程都讲错——见第 8 节。

### 4.2 前向传播方程逐行解读

设第 j 个记忆细胞为 c_j。三组净输入（u 遍历所有可作为输入的单元）：

$$net_{c_j}(t) = \sum_u w_{c_j u}\,y^u(t-1)$$
$$net_{in_j}(t) = \sum_u w_{in_j u}\,y^u(t-1)$$
$$net_{out_j}(t) = \sum_u w_{out_j u}\,y^u(t-1)$$

两个门的激活（sigmoid，挤到 [0,1]）：

$$y^{in_j}(t) = f_{in_j}(net_{in_j}(t)), \qquad y^{out_j}(t) = f_{out_j}(net_{out_j}(t))$$

**细胞内部状态 s（核心！）**：

$$s_{c_j}(0) = 0, \qquad s_{c_j}(t) = \underbrace{s_{c_j}(t-1)}_{\text{CEC：自连接 1.0}} + \underbrace{y^{in_j}(t)\,g(net_{c_j}(t))}_{\text{被输入门过滤的新信息}}$$

逐项看：
- $s_{c_j}(t-1)$ 这一项前面的系数是 **1.0**——这就是 CEC，旧状态无损地传过来。
- $g(\cdot)$ 是输入挤压函数（值域 [−2,2]），把候选输入规整。
- $y^{in_j}(t)$ 是输入门，∈[0,1]，**逐元素乘**在候选输入上：门关→新信息进不来，状态保持；门开→新信息加进去。
- 注意是**加法**更新，不是覆盖。这正是后来 ResNet 残差连接、Transformer 残差流的同一思想：用加法保护梯度通路。

**细胞输出**：

$$y^{c_j}(t) = y^{out_j}(t)\,h(s_{c_j}(t))$$

- $h(\cdot)$ 是输出挤压函数（值域 [−1,1]）。
- $y^{out_j}(t)$ 是输出门，∈[0,1]，**逐元素乘**：门关→外界读不到这个细胞，门开→放行。

### 4.3 为什么梯度不再消失

关键在内部状态的更新 $s_{c_j}(t) = s_{c_j}(t-1) + \dots$。误差对 $s_{c_j}$ 反传时，$\partial s_{c_j}(t)/\partial s_{c_j}(t-1) = 1.0$。**连乘 1.0 任意多次还是 1.0**——第 2.2 节那个致命连乘被彻底拆掉了。

论文的训练算法是 RTRL 的变体 + 截断 BPTT：误差进入细胞输出后，先被输出门和 $h'$ 缩放一次，进入 CEC 后**可以无损地一路反传回任意久远**；只有当它要离开细胞（穿过输入门和 g）时才被再缩放一次然后截断。所以"截断"不影响长程误差流。复杂度 O(W)，且 **local in space and time**（每步更新代价与序列长度、网络规模无关）——这是 LSTM 能扩展的工程根基。

### 4.4 记忆细胞块

S 个记忆细胞可以共享同一对输入/输出门，构成一个"记忆细胞块 (memory cell block of size S)"。共享门让网络能存储**分布式**的信息（多个细胞协同），而代价只是一对门。

## 5. 两个工程坑：滥用与漂移

论文很诚实地讨论了两个实际问题，这部分常被教程略过：

### 5.1 滥用问题 (Abuse problem)

训练初期，网络可能**滥用记忆细胞当偏置单元**——让它的状态恒定，纯粹当成下游单元的自适应阈值。这样的细胞后续很难"释放"出来做正经的记忆工作。
解药：(1) 顺序构建网络（Fahlman 式，需要时才加细胞）；(2) 给输出门一个负的初始偏置，把初始细胞激活推向 0。

### 5.2 内部状态漂移 (Internal state drift)

如果某个细胞的输入长期同号（总是正或总是负），内部状态 s 会**单调漂移**到很大的绝对值，导致 $h'(s)$ 饱和、梯度又变小。
解药：把输入门的初始偏置也推向 0，让早期"少存一点"，避免漂移。

> 这两个坑的存在，其实暗示了**原始 LSTM 缺一个东西：主动遗忘的能力**。状态只能加、不能减，迟早出问题。这正是 2000 年遗忘门被发明的动机。

## 6. 代码骨架：现代 PyTorch 风格的 LSTM 单元

下面是带遗忘门的现代 LSTM（注意与 1997 原版的区别已标注）：

```python
import torch, torch.nn as nn

class LSTMCell(nn.Module):
    def __init__(self, d_in, d_hid):
        super().__init__()
        # 一次性算 4 个门：输入门 i、遗忘门 f、候选 g、输出门 o
        self.W = nn.Linear(d_in + d_hid, 4 * d_hid)
        self.d_hid = d_hid

    def forward(self, x, state):
        h_prev, c_prev = state                       # c 即论文的内部状态 s
        gates = self.W(torch.cat([x, h_prev], dim=-1))
        i, f, g, o = gates.chunk(4, dim=-1)
        i = torch.sigmoid(i)                         # 输入门 y^in
        f = torch.sigmoid(f)                         # 遗忘门（1997 原版没有！恒为 1）
        g = torch.tanh(g)                            # 候选输入 g(net_c)
        o = torch.sigmoid(o)                         # 输出门 y^out
        c = f * c_prev + i * g                       # 内部状态更新（CEC 在此）
        h = o * torch.tanh(c)                        # 细胞输出 y^c = y^out · h(s)
        return h, (h, c)
```

把 `f` 那一行删掉、令 `c = c_prev + i * g`，就得到 **1997 原版 LSTM**。可以清楚看到：CEC 就是 `c = (...)*c_prev + ...` 里 `c_prev` 前面那个系数——原版恒为 1.0，现代版交给遗忘门学习。

## 7. 实验结果与意义

论文做了 6 组实验，核心结论：

- **嵌入式 Reber 文法 (Exp 1)**：标准循环网络基准。LSTM 总能学会，且比 RTRL/ELM/RCC 快得多。这是论文里输出门作用最明显的例子。
- **带噪长程序列 (Exp 2)**：最难的子任务有数百个干扰符号、最小时间间隔 **1000 步**。LSTM 解决了；RTRL 和 BPTT 在 10 步间隔就已失败——所以后续实验干脆不再列它们。
- **Exp 3–6**：连续值、实值条件期望、噪声与信号同线等更难的任务，"从未被任何循环网络算法解决过"。

意义分层：

1. **诊断层面**：第一次把"梯度消失"从模糊的经验变成精确的数学（公式 2 的连乘）。
2. **架构层面**：CEC + 门控成为此后 20 年序列建模的默认骨架。GRU（#23，2014）是它的简化版。
3. **思想层面**：**"用加法 + 门控保护梯度通路"**——这个思想后来出现在 Highway Network、ResNet 残差连接（#13）、Transformer 残差流里。LSTM 是这一思想的鼻祖。
4. **应用层面**：2007 年后，LSTM 撑起了语音识别（Graves）、手写识别、Google 翻译（2016 GNMT）、Siri——直到 2017 年 Transformer 接棒。

## 8. 常见误解与澄清

| 误解 | 实情 |
|---|---|
| "1997 原版 LSTM 有遗忘门" | **没有**。原版只有输入门和输出门，内部状态只能加、不能主动清零。遗忘门是 Gers, Schmidhuber & Cummins 1999/2000《Learning to Forget》加的。今天的"标准 LSTM"是这个增强版。 |
| "LSTM 有窥孔连接 (peephole)" | 原版没有。Peephole（让门也能看到内部状态 s）也是 Gers & Schmidhuber 2000 补的。 |
| "LSTM 彻底解决了梯度消失" | 缓解，不是消灭。CEC 让梯度能跨越上千步，但门控本身仍有梯度、深层堆叠仍会衰减。真正"几乎无衰减"的长程依赖要等 Transformer 的自注意力（O(1) 路径长度）。 |
| "LSTM 和 RNN 是两种东西" | LSTM **是**一种 RNN——它就是把普通 RNN 的隐藏单元换成记忆细胞。 |
| "门控是为了'选择性记忆'这种拟人化目的" | 门控的**数学动机**是解决第 3.2 节的输入/输出权重冲突。"选择性记忆"是它的效果，不是设计出发点。 |
| "Hochreiter & Schmidhuber 发现了梯度消失" | Hochreiter 1991 硕士论文确实最早严格分析，但 Bengio et al. 1994 独立、且用英语让问题进入主流。两条线都要记。 |

## 9. 局限与后续填坑

| LSTM（1997 原版）的局限 | 后续解药 | 关键论文 |
|---|---|---|
| 内部状态只能加、不能主动遗忘 → 漂移 | 遗忘门 | Gers et al. 2000《Learning to Forget》 |
| 门看不到内部状态 | 窥孔连接 | Gers & Schmidhuber 2000 |
| 参数多、训练慢 | 简化为 GRU（合并门、去掉独立细胞状态） | Cho et al. 2014 (#23) |
| 严格顺序计算，无法并行 → 训练慢 | 自注意力，全序列并行 | Transformer 2017 (#24) |
| 长程依赖仍随深度衰减，路径长度 O(n) | 自注意力路径长度 O(1) | Transformer 2017 (#24) |
| 单向，只能看过去 | 双向 LSTM | Graves & Schmidhuber 2005 |
| 难以扩展到极长上下文 | 注意力 + 稀疏/线性注意力 | 整个 Cluster 5 之后 |

最后两行是 LSTM 最终被取代的根因：**它的顺序性既是优点（天然处理变长序列）也是死穴（无法利用 GPU 的并行）**。Transformer 用"放弃循环、全靠注意力"换来了并行训练，这才有了今天的大模型。
