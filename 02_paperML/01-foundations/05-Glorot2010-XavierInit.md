# Xavier 初始化：让深层网络从第一步就训得动
**Understanding the difficulty of training deep feedforward neural networks**
Glorot & Bengio · *AISTATS 2010* · PMLR 9:249–256

---

## 一句话总结

DBN（#4）用"无监督预训练"绕开了"深层网络训不动"的问题。这篇论文不绕——它**正面诊断**：训不动的根本原因之一是随机初始化把每一层的激活方差和梯度方差搞乱了，逐层相乘后要么指数衰减要么指数爆炸。然后它给出一个一行公式的解药——**按 $\sqrt{6/(n_{in}+n_{out})}$ 缩放初始权重**，让方差逐层守恒。这个公式以第一作者的名字流传为 **Xavier 初始化**（也叫 Glorot 初始化），是今天每个深度学习框架 `Linear`/`Conv` 层的默认初始化。

> "Keeping the layer-to-layer transformations such that both activations and gradients flow well (i.e. with a Jacobian around 1) appears helpful."

---

## 1. 历史定位：从"绕过去"到"看清楚"

2006 年 DBN 之后，"深度可训练"成了既成事实，但靠的是各种**预训练 / 特殊初始化的偏方**——RBM 预训练、去噪自编码器预训练。大家知道"预训练有用"，但**不知道它到底修好了什么**。

2009 年 Erhan et al. 的分析指出：无监督预训练的作用其实是"把参数放进一个更好的吸引盆"——本质是一种**初始化**。这句话点醒了 Glorot 和 Bengio：

> 既然预训练的好处归根结底是"好的初始化"，那我们能不能跳过预训练，**直接搞清楚什么样的初始化是好的**？

这篇 AISTATS 2010 论文就是这个追问的产物。它的标题很朴素——"理解深层前馈网络训练之难"——没有炫目的新模型，只有**诊断 + 一行公式**。但正是这种"看清楚"的工作，让深度学习从炼丹术往工程学迈了一大步。它和下一个 Cluster 要读的 AlexNet 一起，宣告了"预训练时代"的结束。

---

## 2. 待解问题：深层网络训练为何如此糟糕

论文用"侦查式实验"——在训练过程中持续监控每一层的**激活值分布**和**梯度分布**。它发现两个并存的病：

### 2.1 病症一：激活饱和

实验网络：1–5 个隐藏层，每层 1000 单元，softmax 输出。论文比较了三种激活函数：

- **Sigmoid**：论文 Figure 2 显示，训练一开始，**最顶层隐藏层的激活迅速被压到 0（饱和）**。sigmoid 输出 0 对应它的饱和区，梯度几乎为 0，于是整个网络的学习被卡住。深度 5 的 sigmoid 网络**全程没能逃出**这个饱和区。
  - 为什么是 sigmoid？因为它的输出**均值不为 0**（值域 [0,1]，均值约 0.5）。论文的解释：随机初始化下，底层算出的 h 对分类没用，softmax 输出 $\text{softmax}(b+Wh)$ 初期更依赖偏置 b，误差梯度于是把 $Wh$ 往 0 推，进而把 h 往 0 推——对 sigmoid 而言，h→0 正好是饱和。
  - 一个意外发现：饱和的单元能**自己慢慢爬出饱和区**——这解释了训练曲线上常见的"平台期 (plateau)"。
- **tanh**：对称、均值为 0，没有顶层饱和。但用标准初始化时，出现**逐层依次饱和**——第 1 层先饱和，然后第 2 层，往上传播（Figure 3 上）。
- **softsign** $x/(1+|x|)$：渐近线是多项式而非指数，更"温柔"。各层**一起、缓慢**地饱和，激活值最终停在"膝盖处"（既非线性区也非饱和区，梯度还能流）。

结论之一：**带小随机权重初始化时，应避免 sigmoid**。它不对称的均值带来糟糕的学习动力学。

### 2.2 病症二：梯度的逐层失衡

Bradley 2009 已观察到：标准初始化后，**反向传播的梯度从输出层往输入层走、方差越来越小**。深层网络底层几乎收不到梯度信号。这是梯度消失在前馈网络里的化身——论文明确指出，这"让人联想到循环网络的梯度问题（Bengio et al. 1994，即 LSTM #3 处理的同一问题）：循环网络展开后就是很深的前馈网络。"

## 3. 核心思想：让方差逐层守恒

### 3.1 直觉

一个信号穿过 d 层网络，每一层都把它的方差乘上某个因子 c。穿过 d 层后方差变成 $c^d$。

- c > 1 → 指数爆炸；
- c < 1 → 指数衰减；
- **c = 1 → 方差守恒，信号既不放大也不消失。**

所以好的初始化目标很明确：**让每一层的方差缩放因子恰好为 1**——前向的激活方差守恒，反向的梯度方差也守恒。这和 LSTM 的 CEC"让缩放因子恒为 1"是同一种思想，只不过这里调的是**初始权重的方差**而非自连接。

### 3.2 论文 Section 4.2 的推导（逐步展开）

**设定**。对称激活函数 f，在 0 处导数为 1（$f'(0)=1$，tanh、softsign 都满足）。记第 i 层激活前的输入 $s^i$、激活后 $z^{i+1}$：

$$s^i = z^i W^i + b^i, \qquad z^{i+1} = f(s^i)$$

反向传播给出两个关系（论文公式 2、3）：

$$\frac{\partial Cost}{\partial s^i_k} = f'(s^i_k)\,W^{i+1}_{k,\bullet}\,\frac{\partial Cost}{\partial s^{i+1}} \tag{2}$$
$$\frac{\partial Cost}{\partial w^i_{l,k}} = z^i_l\,\frac{\partial Cost}{\partial s^i_k} \tag{3}$$

**线性近似**。在初始化时刻，权重小、激活落在 0 附近的线性区，所以 $f'(s^i_k)\approx 1$（公式 4）。再假设权重独立同分布、各输入特征方差相同。

**前向方差递推**。第 i 层激活的方差（公式 5）：

$$Var[z^i] = Var[x]\prod_{i'=0}^{i-1} n_{i'}\,Var[W^{i'}]$$

直觉：每穿过一层，方差被乘上 $n_{i'}\,Var[W^{i'}]$——$n_{i'}$ 是该层输入维度（求和 $n$ 项，每项方差相加），$Var[W^{i'}]$ 是权重方差。

**反向梯度方差递推**（公式 6）：

$$Var\left[\frac{\partial Cost}{\partial s^i}\right] = Var\left[\frac{\partial Cost}{\partial s^d}\right]\prod_{i'=i}^{d} n_{i'+1}\,Var[W^{i'}]$$

**两个守恒条件**。前向要激活方差逐层不变（公式 8 → 10）：

$$\forall i,\quad n_i\,Var[W^i] = 1 \tag{10}$$

反向要梯度方差逐层不变（公式 9 → 11）：

$$\forall i,\quad n_{i+1}\,Var[W^i] = 1 \tag{11}$$

### 3.3 矛盾与折中

公式 (10) 要 $Var[W^i]=1/n_i$（用扇入 fan-in），公式 (11) 要 $Var[W^i]=1/n_{i+1}$（用扇出 fan-out）。除非每层等宽，否则**两者不能同时满足**。

论文取调和折中（公式 12）：

$$\boxed{\;Var[W^i] = \dfrac{2}{n_i + n_{i+1}}\;} \tag{12}$$

分母是扇入与扇出之和，分子 2 让它在等宽时退化为 $1/n$。

### 3.4 从方差推出那一行初始化公式

公式 (12) 给的是**方差**。实际初始化要给一个**均匀分布的区间**。对 $U[-a,a]$，方差是 $a^2/3$。令：

$$\frac{a^2}{3} = \frac{2}{n_j + n_{j+1}} \;\Longrightarrow\; a^2 = \frac{6}{n_j + n_{j+1}} \;\Longrightarrow\; a = \frac{\sqrt{6}}{\sqrt{n_j + n_{j+1}}}$$

于是得到论文公式 (16)，即 **Xavier 归一化初始化**：

$$\boxed{\;W \sim U\left[-\dfrac{\sqrt{6}}{\sqrt{n_j+n_{j+1}}},\; \dfrac{\sqrt{6}}{\sqrt{n_j+n_{j+1}}}\right]\;} \tag{16}$$

那个 $\sqrt{6}$ 不是魔法常数——它就是"方差 $2/(n_j+n_{j+1})$"换算成"均匀分布半宽"时 $\sqrt{3\times 2}$ 的结果。

**对比标准初始化的失败**。论文当时常用的标准初始化是 $U[-1/\sqrt n, 1/\sqrt n]$，它对应 $n\,Var[W] = n\cdot\frac{(1/\sqrt n)^2}{3} = \frac{1}{3}$（公式 15）。$1/3 < 1$——所以梯度方差逐层乘 $1/3$、指数衰减。这正是病症二的数学根源。Xavier 初始化把这个因子从 $1/3$ 修正到约 1。

## 4. 代码骨架

```python
import torch, torch.nn as nn, math

# 手写 Xavier 均匀初始化（论文公式 16）
def xavier_uniform_(W, fan_in, fan_out):
    a = math.sqrt(6.0 / (fan_in + fan_out))
    with torch.no_grad():
        return W.uniform_(-a, a)

# 框架内置版本（等价）
layer = nn.Linear(256, 512)
nn.init.xavier_uniform_(layer.weight)          # U[-√(6/(fan_in+fan_out)), …]
# nn.init.xavier_normal_(layer.weight)          # 正态版：std=√(2/(fan_in+fan_out))

# ReLU 网络应改用 He 初始化（见第 6 节）——方差多一个因子 2
relu_layer = nn.Linear(256, 512)
nn.init.kaiming_uniform_(relu_layer.weight, nonlinearity='relu')
```

`nn.init.xavier_uniform_` 就是公式 (16) 的直接实现。这一行，是这篇论文留给每一个现代网络的遗产。

## 5. 实验结果与意义

论文在 Shapeset-3×2、MNIST、CIFAR-10、Small-ImageNet 上测了 5 隐藏层网络。Table 1（测试错误率，越低越好）：

| 激活 / 初始化 | Shapeset | MNIST | CIFAR-10 |
|---|---|---|---|
| Sigmoid（标准初始化） | 82.61 | 2.21 | 57.28 |
| Tanh（标准初始化） | 27.15 | 1.76 | 55.9 |
| **Tanh N（Xavier 初始化）** | **15.60** | **1.64** | **52.92** |
| Softsign N | 16.06 | 1.72 | 53.8 |

Shapeset 上 tanh 从 27.15% 降到 15.60%——**仅改初始化，错误率近乎砍半**。论文还监控了每层 Jacobian 的奇异值：Xavier 初始化下约 **0.8**（接近理想的 1），标准初始化下只有 **0.5**（方差在衰减）。

意义分层：

1. **直接结论**：好的初始化能消除"纯监督深网"和"预训练深网"之间的大部分差距——**预训练不是必需的**。
2. **方法论**：把"训练困难"从玄学变成可监控、可分析的对象。"训练时盯着每层激活和梯度的分布"成了此后调试深度网络的标准手段。
3. **思想血脉**："让方差/信号逐层守恒"这个原则，后来在 BatchNorm（#8，直接归一化激活）、残差连接（#13，用恒等映射保护方差）、Transformer 的 LayerNorm（#10/#24）里反复出现。Xavier 初始化是这条线的起点。

## 6. 常见误解与澄清

| 误解 | 实情 |
|---|---|
| "Xavier 初始化适用于所有网络" | **不适用于 ReLU**。Xavier 的推导假设激活函数对称、$f'(0)=1$（tanh、softsign）。ReLU 砍掉一半激活、不对称。He et al. 2015（Kaiming 初始化）重新推导，得到 $Var[W]=2/n_{in}$——多一个因子 2 补偿 ReLU 的"半数清零"。**现代 ReLU 网络该用 He 初始化，不是 Xavier**。 |
| "论文叫 Xavier 初始化" | 论文里从没出现"Xavier initialization"——论文称之为 "normalized initialization"。"Xavier"是社区拿第一作者的名字起的昵称。正式也叫 "Glorot initialization"。 |
| "Xavier 初始化只有均匀分布版" | 还有正态版：$W\sim\mathcal{N}(0,\,2/(n_{in}+n_{out}))$。框架里是 `xavier_normal_`。两者方差相同。 |
| "有了 Xavier 初始化就不会梯度消失了" | 它只保证**初始化时刻**方差守恒。训练几步后权重就变了、线性近似失效（论文 Section 4.3 明说）。极深网络仍需 BatchNorm、残差连接来持续维持。Xavier 是"良好开局"，不是"终身保险"。 |
| "$\sqrt 6$ 是经验调出来的" | 不是。$\sqrt 6 = \sqrt{3\times 2}$——是把方差 $2/(n_{in}+n_{out})$ 换算成均匀分布半宽时的纯数学结果。 |
| "sigmoid 一无是处" | sigmoid 作为隐藏层激活确实不好（本文证明）。但作为**门控**（LSTM 的门、注意力的 gating）和**二分类输出**它仍然不可替代——值域 [0,1] 正是概率所需。 |

## 7. 局限与后续填坑

| Xavier 初始化的局限 | 后续解药 | 关键论文 |
|---|---|---|
| 假设激活对称、$f'(0)=1$，不适配 ReLU | He / Kaiming 初始化（方差 $\times 2$） | He et al. 2015 |
| 只保证初始化时刻方差守恒，训练中失效 | 训练全程归一化激活 | BatchNorm (#8), LayerNorm (#10) |
| 极深网络（>30 层）仍训不动 | 残差连接，用恒等映射保护信号 | ResNet (#13) |
| 推导基于线性近似，非线性强时不准 | 自归一化网络 (SELU)、更精细的方差分析 | Klambauer et al. 2017 |
| 没考虑卷积层的感受野结构 | 卷积版 fan-in/fan-out 计算 | He 2015（同时处理） |
| 对注意力/Transformer 不直接适用 | 专门的 Transformer 初始化方案 | T-Fixup, DeepNet 等 |

总结这张表：Xavier 初始化提出的**"方差逐层守恒"原则是永恒的**，但它的**具体公式**只是这个原则在 tanh 上的一个特例。He 初始化、BatchNorm、残差连接，都是同一原则在不同场景下的再实现。

## 8. 与本路线图后续论文的关联

- **#4 DBN**：DBN 用预训练**绕过**坏初始化，本文**直接修好**初始化——后者更简单，于是预训练范式退场。两篇连读能看清这个交接。
