# LeNet：把反向传播折进二维卷积
**Gradient-Based Learning Applied to Document Recognition**
LeCun, Bottou, Bengio & Haffner · *Proceedings of the IEEE* 86(11), 2278–2324 · 1998-11

---

## 一句话总结

这篇 46 页的长文（本教程聚焦其前半部分的 LeNet-5）做成了一件事：**把全连接网络替换成"局部感受野 + 权重共享 + 下采样"三件套，让网络的结构本身就编码了图像的平移不变性**。结果是参数量从几十万降到 6 万，泛化能力反而更强。今天所有卷积网络——AlexNet、VGG、ResNet——都是这篇论文里 LeNet-5 的直系后代。

> "Convolutional Networks force the extraction of *local* features by restricting the receptive fields of hidden units to be local."

如果说 Rumelhart 1986 教会网络"学习表示"，那么这篇论文教会网络**学习的同时尊重数据的几何结构**。

## 1. 历史定位：1989→1998 的十年长征

LeNet 不是一篇论文，而是一个系列。理解这一点很重要：

| 版本 | 年份 | 关键事件 |
|---|---|---|
| LeNet-1 | 1989 | LeCun 在贝尔实验室，第一个用反向传播训练的卷积网络，识别邮政编码 |
| LeNet-4 / Boosted | 1994–95 | 架构迭代 |
| **LeNet-5** | **1998** | 本论文的最终形态，配 MNIST 基准 + 商用支票识别系统 |

它的两条思想血脉：

1. **Hubel & Wiesel（1962，诺奖工作）**：猫的视觉皮层里有"简单细胞"（检测特定朝向的边缘）和"复杂细胞"（对位置有一定容忍度）。
2. **Fukushima 的 Neocognitron（1980）**：第一个把简单/复杂细胞做成多层网络的模型。但 Neocognitron **没有全局监督训练**——它用的是无监督的竞争学习，效果有限。

LeCun 的飞跃：**把 Neocognitron 的结构 + Rumelhart 的反向传播结合起来**。结构提供归纳偏置，反向传播提供端到端优化。这就是 LeNet。

而且这篇论文不是学术玩具——文中明确写道，基于 LeNet 的支票识别系统部署在 NCR 的银行系统里，"reading several million checks per day"。**1998 年，卷积网络已经在为真实世界数钱了。**

## 2. 待解问题：为什么全连接网络处理图像如此糟糕

假设你要识别 32×32 的手写数字，用一个全连接网络，第一隐藏层 100 个单元。论文第 5 页把问题点得很清楚，拆成三条：

### 2.1 参数爆炸

32×32 = 1024 个输入，全连接到 100 个隐藏单元 = **102,400 个权重**——仅第一层。参数越多，VC 维（"有效容量" h）越大。论文给出的泛化界（公式 1）：

$$E_{test} - E_{train} = k \left(\frac{h}{P}\right)^\alpha \tag{1}$$

P 是训练样本数，α 在 0.5–1.0 之间。**h 越大，要么需要更多数据 P，要么泛化差距越大**。全连接网络在图像上注定参数过剩。

### 2.2 没有平移不变性

全连接网络中，输入像素的"顺序"是任意的——你把图像所有像素打乱顺序重新训练，网络性能完全不变。这说明它**完全没有利用"相邻像素相关"这一图像的根本结构**。

后果：一个在左上角学会识别"横线端点"的单元，对右下角出现的同样横线端点毫无办法。每个位置都要重新学一遍。

### 2.3 对几何形变脆弱

手写字符即使做了尺寸归一化，仍有位置、倾斜、笔画粗细的变化。全连接网络要靠"看足够多的形变样本"硬记，数据需求量极大。

**核心矛盾**：图像有强烈的 2D 局部结构，而全连接网络把这个结构完全扔掉了。

## 3. 核心思想：三件套——局部感受野、权重共享、下采样

论文第 6 页提出卷积网络的三个架构思想，每一个都对应解决上面一个问题。

### 3.1 局部感受野 (Local Receptive Fields)

每个隐藏单元只连接输入的一个小邻域（LeNet-5 里是 5×5）。

直觉：边缘、角点、笔画端点这些初级特征**本来就是局部的**——你不需要看整张图才能判断"这里有一条横线"。
收益：第一层每个单元只有 5×5=25 个权重，而不是 1024 个。

### 3.2 权重共享 (Shared Weights / Weight Replication)

一个"特征图"(feature map) 里的所有单元**共用同一组 25 个权重**。也就是说，同一个 5×5 滤波器在整张图上滑动。

直觉：如果"检测横线端点"这个滤波器在左上角有用，它在右下角同样有用——**特征检测器应该与位置无关**。
收益：
- 参数量再次暴跌。LeNet-5 的 C1 层 6 个特征图，每个 25 权重 + 1 偏置 = **总共才 156 个可训练参数**，却覆盖了 122,304 个连接。
- 自动获得平移等变性：输入平移，输出特征图同样平移。论文原话："if the input image is shifted, the feature map output will be shifted by the same amount, but will be left unchanged otherwise."

这个"滑动同一个滤波器"的操作，数学上就是**离散卷积**——这才是"卷积网络"得名的由来。

### 3.3 空间下采样 (Spatial Sub-sampling)

每隔几层做一次降分辨率（LeNet-5 里 2×2 平均池化）。

直觉：一旦检测到某个特征，它的**精确位置**就不重要了，重要的是它**大致在哪、与其他特征的相对关系**。论文举例："once we know the input contains the endpoint of a roughly horizontal segment in the upper left area … we can tell the input is a 7."
收益：
- 对小幅形变和位移更鲁棒。
- 分辨率降低的同时，特征图数量增加（"bi-pyramid" 双金字塔结构）——空间信息换成语义丰富度。

### 3.4 三件套合起来

```
局部感受野  → 解决参数爆炸（每单元只连小邻域）
权重共享    → 解决平移不变 + 进一步压参数
下采样      → 解决形变脆弱 + 逐层抽象
```

**关键洞察**：这三件套不是"训练技巧"，而是把"图像是什么"这一先验知识**直接焊进了网络结构**。这就是"归纳偏置 (inductive bias)"——结构本身约束了网络只能学到合理的函数。

## 4. LeNet-5 架构逐层精解

LeNet-5 有 7 层（不含输入），输入 32×32（比最大字符 20×20 大，目的是让笔画端点这种特征也能落在高层感受野的中心）。

```
INPUT 32×32
  │  卷积 5×5
C1: 6@28×28      ── 6 个特征图，156 参数，122,304 连接
  │  下采样 2×2
S2: 6@14×14      ── 12 参数，5,880 连接
  │  卷积 5×5（稀疏连接，见 Table I）
C3: 16@10×10     ── 1,516 参数，151,600 连接
  │  下采样 2×2
S4: 16@5×5       ── 32 参数，2,000 连接
  │  卷积 5×5（因 S4 是 5×5，输出 1×1）
C5: 120@1×1      ── 48,120 参数
  │  全连接
F6: 84 单元      ── 10,164 参数
  │  RBF
OUTPUT: 10       ── 欧氏径向基
```

### 4.1 C1 — 第一卷积层

6 个特征图，每个 28×28。为什么是 28？输入 32，5×5 卷积无填充，输出 32−5+1 = 28。每个特征图的单元共享 5×5+1 = 26 个参数，6 个图共 156 个。

### 4.2 S2 — 第一下采样层

6 个特征图，14×14（28 减半）。每个单元取 C1 对应 2×2 邻域的**和**，乘一个可训练系数，加一个可训练偏置，再过 sigmoid。所以每个特征图只有 2 个参数，6 个图共 12 个。

注意：这不是现代的 max-pooling，而是"可训练的加权平均池化"。系数小→近似线性模糊；系数大→近似"noisy OR / noisy AND"。

### 4.3 C3 — 稀疏连接的卷积层

这是 LeNet-5 最精巧的一层。16 个特征图，但**不是每个 C3 特征图都连到全部 6 个 S2 特征图**——而是按 Table I 的稀疏模式连接：

- 前 6 个 C3 图：各取 S2 的 3 个相邻图
- 接下来 6 个：各取 S2 的 4 个相邻图
- 再 3 个：各取 4 个不相邻图
- 最后 1 个：取全部 6 个

为什么不全连接？论文给了两个理由：(1) 控制连接数；(2) **打破对称性**——强迫不同特征图抽取互补的特征。这个"稀疏连接"思想在 2012 年 AlexNet 的"分组卷积"和 2017 年的 grouped/depthwise conv 里再次复活。

### 4.4 C5、F6 — 全连接收尾

C5 名义上是卷积层（120 个图，5×5 卷积），但因为 S4 恰好是 5×5，卷积输出退化成 1×1，所以实际是全连接。F6 有 84 个单元——这个奇怪的数字来自输出层设计：84 = 7×12，是一个字符的"风格化位图"尺寸。

### 4.5 激活函数：缩放 tanh

F6 及之前各层用缩放双曲正切（公式 5、6）：

$$x_i = f(a_i), \qquad f(a) = A\tanh(Sa) \tag{5, 6}$$

A = 1.7159。这个常数不是随便选的：它让函数在输入 ±1 时输出也接近 ±1，使**输出的均值约 0、方差约 1**——这是 Glorot 2010（本路线图 #5）权重初始化理论的雏形。论文已经知道"保持各层激活的方差稳定能加速收敛"。

### 4.6 输出层：欧氏 RBF（而非 softmax）

输出层是 10 个欧氏径向基函数单元（公式 7）：

$$y_i = \sum_j (x_j - w_{ij})^2 \tag{7}$$

每个 RBF 单元算 F6 的 84 维输出向量与一个**固定参数向量**（手工设计成对应数字的 7×12 风格化位图）的欧氏距离平方。距离越小 → y_i 越小 → 越可能是该类。

为什么不用现在标准的"1-of-N + softmax"？论文给的理由很有前瞻性：当类别数超过几十时，one-hot 编码下"大多数输出要为 0"对 sigmoid 是困难的；而**分布式输出编码**让相似字符（如大写 O、小写 o、数字 0）有相似的编码，便于后续语言模型纠错。

## 5. 损失函数：从 MSE 到"竞争性"损失的推导

### 5.1 朴素版：最大似然 / MSE

最简单的损失（公式 8）只惩罚正确类 RBF 的输出：

$$E(W) = \frac{1}{P}\sum_{p=1}^{P} y_{D^p}(Z^p, W) \tag{8}$$

y_{D^p} 是正确类对应的 RBF 输出（=距离平方），最小化它就是让 F6 输出靠近正确类的目标向量。

**但这个损失有一个致命漏洞**：如果允许 RBF 的参数向量也参与训练，损失存在一个平凡解——让所有 RBF 参数向量相等、F6 恒等于那个向量，则所有 y_i = 0，损失为 0，但网络什么也没学到（"collapsing phenomenon"）。

### 5.2 改进版：加入竞争项

论文用公式 9 修复（这一步推导值得逐项看）：

$$E(W) = \frac{1}{P}\sum_{p=1}^{P}\left( y_{D^p}(Z^p,W) + \log\Big(e^{-j} + \sum_i e^{-y_i(Z^p,W)}\Big)\right) \tag{9}$$

逐项解读：

- **第一项 $y_{D^p}$**：和公式 8 一样，把正确类的距离压小。
- **第二项 $\log(e^{-j} + \sum_i e^{-y_i})$**：注意求和遍历**所有类** i。每个 $e^{-y_i}$ 在 y_i 小时（即第 i 类被认为很可能时）变大。整个 log 项变大。最小化损失 → 要把这一项压小 → 要让**错误类的 y_i 变大**（距离拉远）。
- 所以第一项"拉近正确类"，第二项"推远错误类"——这就是**判别式 (discriminative) 训练**。
- 常数 $e^{-j}$ 项对应一个"垃圾类"(rubbish class)，防止错误类的惩罚被无限抬高。

把第二项展开看：$\log\sum_i e^{-y_i}$ 正是 **log-sum-exp**。如果把 $-y_i$ 看作 logit，这一项就是 **softmax + 交叉熵** 的等价形式！换句话说，**LeNet 在 1998 年已经在用 softmax 交叉熵了**，只是写成了 RBF 距离的语言。后来的分类网络只是把它写回了标准形式。

### 5.3 训练：带权重共享的反向传播

梯度仍然用反向传播算，但因权重共享需要一个小改动（论文第 9 页）：

> "first compute the partial derivatives of the loss function with respect to each *connection*, as if the network were a conventional multi-layer network without weight sharing. Then the partial derivatives of all the connections that share a same parameter are **added** to form the derivative with respect to that parameter."

也就是说：**先把共享权重当成独立权重各自算梯度，再把它们加起来**。这和 Rumelhart 1986 处理循环网络（BPTT）的技巧完全一样——共享参数的梯度求和。这一句是现代框架里 `Conv2d` 自动微分的本质。

优化器用的是随机梯度下降的一个对角 Levenberg-Marquardt 近似（公式 3 的二阶变体），学习率按 0.0005→0.0002→0.0001→0.00005→0.00001 的时间表衰减。

## 6. 代码骨架：现代 PyTorch 复现 LeNet-5

```python
import torch.nn as nn

class LeNet5(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, kernel_size=5),    # C1: 1→6, 32×32→28×28
            nn.Tanh(),
            nn.AvgPool2d(kernel_size=2),       # S2: 28×28→14×14
            nn.Tanh(),
            nn.Conv2d(6, 16, kernel_size=5),   # C3: 6→16, 14×14→10×10
            nn.Tanh(),                         #  （现代实现一般省略 Table I 的稀疏连接）
            nn.AvgPool2d(kernel_size=2),       # S4: 10×10→5×5
            nn.Tanh(),
            nn.Conv2d(16, 120, kernel_size=5), # C5: 16→120, 5×5→1×1
            nn.Tanh(),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(120, 84), nn.Tanh(),     # F6
            nn.Linear(84, n_classes),          # 现代用 Linear+softmax 代替 RBF
        )

    def forward(self, x):
        return self.classifier(self.features(x))
```

对照原文，现代实现做了三处简化：(1) C3 用全连接代替 Table I 稀疏连接；(2) RBF 输出层换成 `Linear`+交叉熵（如第 5.2 节所证，本质等价）；(3) 平均池化常被 max-pooling 取代。骨架不变——**三件套依然在 `Conv2d` + `AvgPool2d` 里**。

## 7. 实验结果与意义

MNIST 数据集本身就是这篇论文的副产品——由 NIST 的 SD-1（高中生手写）和 SD-3（人口普查局员工手写）混合、归一化到 28×28 而成。这个数据集后来成了机器学习界用了 25 年的"果蝇"。

LeNet-5 在 MNIST 上：训练 20 轮，测试错误率稳定在 **0.95%**，训练错误率 19 轮后到 0.35%。论文同时对比了一大堆方法（线性分类器、K-NN、PCA+多项式、RBF 网络、各种 SVM、TDNN……），结论：**专门设计的卷积网络打败了所有通用方法**。论文还发现，用形变扩增把训练集从 6 万扩到 60 万，错误率进一步下降——这是**数据增强 (data augmentation)** 的早期实证。

意义分四层：

1. **架构层面**：确立了"卷积—池化—卷积—池化—全连接"这一沿用 20 年的视觉网络模板。
2. **方法论层面**：证明"结构化归纳偏置 + 端到端梯度学习"优于"手工特征 + 通用分类器"。这是 2012 年深度学习革命的预演。
3. **工程层面**：第一个大规模商用的神经网络（支票识别）。
4. **学科层面**：MNIST 成为基准，"在 MNIST 上跑通"成了无数研究者入门深度学习的第一步。

## 8. 常见误解与澄清

| 误解 | 实情 |
|---|---|
| "LeCun 发明了卷积网络" | 卷积结构的思想源头是 Fukushima 的 Neocognitron（1980）和更早的 Hubel-Wiesel。LeCun 的贡献是**第一个用全局反向传播训练卷积网络**，并做成工程系统。 |
| "LeNet 用的是 max-pooling" | 不是。LeNet-5 用的是**可训练系数的平均池化**（2×2 求和×系数+偏置）。Max-pooling 是后来（Ranzato 2007 附近）才流行的。 |
| "LeNet 输出层是 softmax" | 形式上是欧氏 RBF。但如第 5.2 节所证，它的判别式损失（公式 9）展开后**等价于 softmax 交叉熵**。 |
| "这篇论文只讲了 LeNet" | LeNet-5 只是前半部分。后半部分提出 **Graph Transformer Networks (GTN)**——把卷积识别器、分割、语言模型串成一个端到端可微的图结构系统。这是"结构化预测 + 神经网络"的极早期工作，被严重低估。 |
| "卷积网络 1998 年就成功了，为什么深度学习等到 2012" | LeNet 在 MNIST 这种小图、小类别上成功了。但扩展到 ImageNet（百万张大图、1000 类）需要：GPU 算力、ReLU、Dropout、更大数据——这些 2012 年才凑齐。LeNet 是对的，只是早了 14 年。 |

## 9. 局限与后续填坑

| LeNet-5 的局限 | 后续解药 | 关键论文 |
|---|---|---|
| tanh/sigmoid 激活，深层梯度消失 | ReLU | AlexNet (#6), Nair-Hinton 2010 |
| 平均池化丢失强响应信息 | Max-pooling | Ranzato 2007 |
| 只能处理小图、少类别 | GPU + 更深网络 | AlexNet (#6) |
| 网络浅（7 层），加深则难训练 | 残差连接、归一化 | ResNet (#13), BatchNorm (#8) |
| 手工设计稀疏连接 (Table I) | 学习式分组卷积 / 注意力 | ResNeXt; ViT (#64) |
| 无正则化，靠早停 | Dropout / 权重衰减 | Dropout (#7) |
| 输入需手工尺寸归一化 | 端到端检测+识别 | Faster R-CNN (#16) |
| 卷积的平移归纳偏置太强，限制大数据下的上限 | 弱归纳偏置的 ViT | ViT (#64) |

最后一行尤其值得玩味：LeNet 的核心贡献——**强归纳偏置**——在 25 年后被 ViT 部分推翻。当数据足够多（JFT-300M 级别）时，Transformer 用更弱的归纳偏置反而超过 CNN。这说明"归纳偏置"是一把双刃剑：数据少时是助力，数据多时是枷锁。

## 10. 与本路线图后续论文的关联

- **#5 Xavier init**：LeNet 的 A=1.7159 缩放 tanh 是"保持激活方差"的雏形，Xavier 给出完整理论。
- **#6 AlexNet**：LeNet 的直接放大版——同样的卷积-池化骨架，加上 ReLU、Dropout、GPU、ImageNet。
- **#13 ResNet**：解决"LeNet 式网络加深就训不动"的问题。
- **#16 Faster R-CNN / #18 U-Net**：把 LeNet 的卷积骨架从"分类"推广到"检测""分割"。
- **#64 ViT**：对 LeNet 核心假设（强卷积归纳偏置）的反叛。

可以说，整个 Cluster 3（视觉 CNN）就是 LeNet 的展开史。
