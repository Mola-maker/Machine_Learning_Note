# 入库流程
1. 选模板（templates/）：概念/论文/推导/复盘四选一，补全 frontmatter。
2. 内容保真：原文的技术结论、例题数字、公式原样保留；转写拿不准处标 [待确认]。
3. 术语对照 GLOSSARY.md：新术语先提议入表（在 PR/提交说明中列明），再在正文使用。
4. 放到所属章节目录，文件名与一级标题一致；同步该章 `00 本章索引.md` 与根 INDEX.md。
5. 跑 link-weaver 补双链；跑 checks 全套；把入库记录写进 CHANGELOG（日常小入库可免）。
