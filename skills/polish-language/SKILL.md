# 语言优化（五阶段）
1. **术语统一**：对照 GLOSSARY.md，把同义异名全部归一；新译名先入表。
2. **句法精简**：删冗词、拆 >60 字长句、补省略主语；不得删限定词与条件（如"当…时""几乎处处"）。
3. **结构重排**：仅当段落顺序明显不合逻辑时才动，且先产出大纲 diff 给用户看再执行。
4. **保真校验**：公式字符串 diff 必须为空；数字、引用逐一与原文对齐；代码块不动。
5. **双语对齐**：中英文/数字间空格、全半角标点、英文术语大小写按原文（如 SVM、Lagrange）。
交付物 = diff + 逐处改动说明（原句→改后+分类：术语/冗词/长句/混排/标点）。
节奏：先 1 篇与用户定风格，再每批 ≤5 篇；RUBRIC 语言维回退即回滚该批。
