# 公式审校
1. 修改前导出该篇全部公式字符串（$...$ 与 $$...$$）存 runs/ 快照。
2. 正文修改后逐条比对：公式集合 diff 必须为空；若确需改公式（如原公式笔误），在 verdict 中单独列明原式→改式与依据来源。
3. 渲染规范：行内 $...$、独立公式 $$...$$；多行推导用 aligned；记号与 GLOSSARY/原文记号表一致。
4. 常见坑：中文标点混入公式、上下标未加花括号、\left\right 不配对、百分号未转义。
