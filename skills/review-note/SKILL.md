# 独立审校清单
对每处 diff 逐项问：
1. 技术含义漂移？（结论、条件、量词、方向）
2. 公式/数字/引用被动过？（与 formula-guard 快照比）
3. 术语与 GLOSSARY 一致？新译名入表了吗？
4. 结构合规？（frontmatter、一级标题唯一、索引同步）
5. 语言真的更好？（不是换个说法而已；无收益改动建议回退）
输出：问题清单（文件/行/问题/严重度）或"通过"结论；有严重问题整批退回，不代改。
