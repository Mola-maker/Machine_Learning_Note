# 价值排序与教学成果检测
## 第一步：确定性特征（脚本，不靠感觉）
跑 `checks/value_features.py` 产出每篇特征 JSON：正文字数、公式数、例题数、图片/画布引用数、
入链数、出链数、小节数、frontmatter 状态、最近更新时间。
## 第二步：价值评分（模型按 RUBRIC-VALUE 打分，0–5/维）
- **枢纽度**：概念在知识图中的位置（前置/枢纽/叶子）与入链支撑。
- **不可替代性**：内容是否别处难得（自有推导、踩坑记录、独有例题）。
- **完备度**：定义—直觉—推导—例题—易错是否齐全（对照 eval/RUBRIC）。
- **直观度**：图示、类比、具体数字例、一步一图的推导密度。
- **时效与对齐**：与课程/考试大纲的贴合与最近修订状态。
总分 = 五维加权（枢纽 25% / 不可替代 25% / 完备 20% / 直观 20% / 对齐 10%），
输出全库排序表（分数 + 每篇一句价值判断）到 `runs/value-rank-<日期>.md`，
并刷新站点数据 `site/src/data/notes.json`。
## 第三步：教学成果检测
从排序与正文里挑"最直观的教学成果"Top 10：图示讲清一个难点、一道例题打通一类题、
一段类比让抽象落地、一张自制流程图/画布。逐条给出：出处篇目、成果类型、为什么直观（一句）、
对应知识点。产出 `runs/teaching-highlights-<日期>.md` 并刷新站点教学成果页数据。
纪律：评分必须落到特征与原文证据，不许只给印象分；同分时枢纽度高者优先。
