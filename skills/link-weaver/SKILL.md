# 双链补织
1. 跑 checks/check_deadlinks.py 与索引覆盖检查，拿到断链/孤儿/未索引清单。
2. 断链：目标笔记存在但改名→更新引用；目标尚不存在→建 status:draft 占位笔记并登记到对应章节索引的"待补"区。
3. 孤儿：在概念最相关的 1–3 篇笔记正文中以自然句子补入双链，不堆"相关链接"垃圾段。
4. 索引：新笔记必须进章节 `00 本章索引.md`（按学习顺序）与根 INDEX.md 的章节入口。
5. 复跑检查确认问题数下降，在 verdict 中报告前后数字。
