# 自迭代日志（方法说明）

本库由一套 agent harness 全自动维护，每周跑一轮（也可手动触发）：

**循环**：Propose（提候选）→ Probe（样本试行 + 打分对比）→ 闸门 → Compose（采纳/否决）→ 沉淀。

**闸门（全过才采纳）**：公式零改动；五项自动检查问题不增；RUBRIC 提升 ≥0.5（小于算噪声）；
留出集体检不回退；独立审校通过。任一不过 → 自动否决并记入 `FAILED_IDEAS.md`。

**回滚**：已采纳改法若在后续检查中导致回退，自动 git revert 并记录原因。

**留痕**：每轮的 proposal / 检查前后 / verdict 都在仓库 `runs/` 目录，可审计。
用户只接收每轮摘要推送，不需要逐项审批（全自动为用户 2026-10-19 指示）。

各轮摘要见仓库 `runs/` 与根目录 `CHANGELOG.md`。
